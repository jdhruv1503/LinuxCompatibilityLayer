## Project Overview

**Thin Linux Compatibility Layer (TLCL)** for ESP32 -- a Unikernel/Library OS that enables execution of standard Linux ELF binaries on ESP32 microcontrollers without an MMU. The system translates POSIX system calls to ESP-IDF/FreeRTOS primitives and uses LittleFS for filesystem storage.

## Build & Run Commands

**Use `tools/build_and_run.py` for all build and simulation tasks.** It handles the two-pass build, symbol export, flash padding, and QEMU timeout.

```bash
# Full workflow: build -> export symbols -> rebuild -> merge -> pad -> simulate
python tools/build_and_run.py

# Build only (no simulation)
python tools/build_and_run.py --build

# Run simulation only (requires previous build)
python tools/build_and_run.py --sim

# Clean build + simulation
python tools/build_and_run.py --clean

# Custom QEMU timeout (default: 20 seconds)
python tools/build_and_run.py --timeout 60

# Verbose output / disable networking
python tools/build_and_run.py --verbose
python tools/build_and_run.py --no-net

# Socket capture for testing dup2 redirection
python tools/build_and_run.py --capture 12345 --timeout 30

# Individual steps
python tools/build_and_run.py --export   # Export symbols only
python tools/build_and_run.py --merge    # Merge + pad binaries only

# Guest applications
python tools/build_and_run.py --build-guest c2_payload              # Build guest ELF only
python tools/build_and_run.py --set-elf c2_payload                  # Set as default ELF
python tools/build_and_run.py --build-guest c2_payload --set-elf c2_payload  # Combined
```

### Why This Script is Required

1. **QEMU NEVER exits on its own** -- even with `-no-reboot`, QEMU continues running if firmware idles. The script enforces a timeout to prevent agent lockups.
2. **Two-pass build** -- symbol export requires a built ELF, then rebuild links against the new symbols.
3. **Flash padding** -- QEMU requires exactly 4MB flash image, padded with zeros.

## Guest ELF Compilation

Guest ELFs must be compiled as **shared objects (ET_DYN)**, NOT relocatable objects (ET_REL). They are built with `-nostdlib -shared -fPIC` and contain **unresolved references** (e.g., `printf`, `socket`) that are resolved at load time by the ELF Loader against the host firmware's exported symbol table.

**Entry point requirement:**
```c
__attribute__((visibility("default")))
int app_main(int argc, char *argv[])
{
    return 0;
}
```

Guest ELFs output to `build/guest_apps/` and are copied to `data/` for inclusion in the LittleFS flash image.

## Architecture

### Execution Model

1. **Bootloader** loads partition table, jumps to Factory App (`main/main.c`)
2. **`app_main`** initializes drivers via `drivers_init_all()` (NVS, network, LittleFS, VFS devices)
3. **Default ELF** (set by `#define DEFAULT_ELF_PATH` in `main.c`, updated via `--set-elf`) is loaded and executed
4. **ELF Loader** (`load_and_run_elf()`) uses `esp_elf_relocate()` to load the binary, then calls `elf.entry(argc, argv)`
5. **Guest runs** as a FreeRTOS task in the same address space -- no process isolation

### Memory Model (No-MMU)

- **Single address space**: FreeRTOS + loaded ELFs share physical RAM
- **IRAM vs DRAM**: Code allocated via `heap_caps_malloc(..., MALLOC_CAP_EXEC)`, data via `MALLOC_CAP_8BIT`
- All binaries must be Position Independent (PIE)

### Core Subsystems

**Symbol Table** (`components/espressif__elf_loader/src/esp_all_symbol.c`): Auto-generated by `tools/export_symbols.py`. Maps POSIX function names to firmware addresses. Customer symbols are checked first, allowing override of libc functions.

**Syscall Shim Layer** (`main/syscalls/`):
- `shim_unistd.c`: FS syscalls with path translation (`/path` -> `/linux/path`), printf/puts interception for C2 redirection, dup2 emulation via global socket state
- `shim_socket.c`: BSD socket syscalls with LwIP errno translation
- `shim_process.c`: Process emulation -- `execve()` creates a new FreeRTOS task (spawn model, no fork)
- `shim_time.c`: POSIX time functions (`clock_gettime`, `gettimeofday`, `nanosleep`, etc.)
- `shim_mem.c`: Per-guest heap accounting (`lcl_heap_register/track_alloc/track_free`)

**Driver Subsystem** (`main/drivers/`): Modular init/deinit via `drivers.h`. Network (OpenEth for QEMU, EMAC for hardware), LittleFS, SD card, and VFS device drivers (`/dev/c2`, `/dev/collision`, `/dev/buzzer`).

**VFS C2 Pipe** (`main/vfs_drivers/vfs_c2_pipe.c`): Redirects stdout to a network socket for C2 command output streaming.

**Guest Apps** (`apps/`): Each subdirectory is a standalone guest ELF (hello_world, c2_bot, c2_payload, map_reduce_worker, collision_guard, etc.).

### Key Design Patterns

- **Path Translation**: Guest `/log.txt` -> VFS `/linux/log.txt`
- **Permission Faking**: `stat()` always returns 0777 (LittleFS lacks permissions)
- **Spawn Model**: `execve()` creates new FreeRTOS task (no fork on ESP32)
- **Errno Translation**: LwIP errors mapped to POSIX errno values
- **Stdout Redirection**: Global socket variable approach (`g_c2_redirect_state`) instead of dup2/FD table manipulation

### Linker Symbol Forcing

All shim functions must be force-linked via `-u symbol_name` in `main/CMakeLists.txt` to prevent the linker from stripping them. This includes shim functions, VFS driver symbols, math functions, and libgcc soft-float helpers. If you add a new shim, add the corresponding `-u` entry.

## Critical Pitfalls

### QEMU

- **Never run QEMU without a timeout wrapper** -- it will hang forever if firmware idles. Always use `build_and_run.py`.
- **Flash must be exactly 4MB** -- `build_and_run.py` handles padding.
- **Networking**: Use `-nic user,model=open_eth` for NAT with DHCP.
- **External connections fail in NAT mode** -- use port forwarding: `hostfwd=tcp::8080-:80`
- **Multi-instance startup**: Use 40+ second timeout. Stagger parallel connections by ~400ms.
- **NAT idle timeouts**: Send data in a single `sendall()` call, not chunked with delays.
- **Throttled sending to ESP32**: Break large payloads into chunks with small delays (1024B/50ms for ELF, 128B/50ms for data) to prevent LwIP buffer exhaustion.
- **No PCAP capture**: Espressif's QEMU doesn't support `-net dump`. Use real hardware for packet capture.

### ESP-IDF Build

- **"Failed to find partition 'linux_fs'"**: Ensure `CONFIG_PARTITION_TABLE_CUSTOM=y` in `sdkconfig.defaults`, delete `sdkconfig`, rebuild.
- **Flash size overflow**: Add `CONFIG_ESPTOOLPY_FLASHSIZE_4MB=y`.

### ELF Loader

- Use `esp_elf_relocate()`, NOT `esp_elf_load()` (doesn't exist).
- Run `export_symbols.py` after first build, then rebuild.
- Add `-u symbol_name` to `main/CMakeLists.txt` for every shim function.

### Stdout/Stdin Redirection

- **NEVER close STDOUT_FILENO** -- ESP32 stdout/stderr share a UART driver. Closing FD 1 breaks all console output.
- Use the global socket variable approach (`g_c2_redirect_state`): set flags, check in `shim_write()`/`shim_read()`, route to socket.
- Use `MSG_DONTWAIT` for socket sends in redirect path.
- If socket send fails in `shim_write`, still return success (prevents crash on C2 disconnect).
- Use raw `read()` on fd=0 instead of `fgets()` for socket-redirected stdin.
- **Buffered reads**: Always read in large chunks (e.g., 1024 bytes), not byte-by-byte. Byte-by-byte causes massive syscall overhead and timeouts.

### C Code

- `c2_redirect_state_t` struct and `g_c2_redirect_state` must be declared BEFORE functions that use them.
- Guest ELF entry points must use `__attribute__((visibility("default")))`.

### Python Tools (Windows)

- **No Unicode**: Windows cmd.exe uses cp1252. Use ASCII: `[OK]` not checkmark, `[X]` not X-mark, `->` not arrow. Use `+---+` box drawing, not Unicode box-drawing characters.
- **UI flicker**: Use cursor-home + clear-to-EOL (`\033[H` + `\033[K`) instead of `clear_screen()`.
- **Strip ANSI from QEMU output**: QEMU emits cursor-movement escape codes that corrupt display. Use a comprehensive regex to strip CSI, OSC, DCS sequences and backspace characters.
